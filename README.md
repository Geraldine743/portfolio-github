# Mini site présentant mes répos GitHub

## Présentation

- Le mini site sera composé de quatres pages : la page d'accueil, la page présentant tous les projets, la page présentant un projet spécifique et la page des mentions légales.
- On retrouvera sur la page d'accueil : une présentation, un lien vers le profil reseau-sociaux, les trois derniers repos.
- Sur la page tout les projets, on aura des filtres et on affichera tout les repos (sans pagination).
- La page projet contiendra les infos du projet, le lien vers le repo GitHub, la visualisation des langages utilisés, le thème du projet.

## Environement technique

- HTML, SCSS, Javasript
- Octokit (le SDK officiel de GitHub)
